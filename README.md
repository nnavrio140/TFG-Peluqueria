# Peluquería Almáchar

## Temática

- Peluquería

## Objetivos

- Aplicación web para gestionar las citas de una peluquería.
- Permite a los clientes reservar citas seleccionando servicio, empleado, fecha y hora disponible.
- Facilita la gestión de citas actuales e históricas según el rol del usuario.

## Funcionalidades

- Roles:
  - Admin: podrá ver todas las citas, gestionar las citas actuales e históricas de todos los usuarios y administrar la información principal de la aplicación.
  - Empleado: podrá ver las citas que tenga asignadas, consultar su agenda y gestionar las citas que debe atender.
  - Cliente: podrá ver sus propias citas, crear nuevas reservas y gestionar sus citas actuales e históricas.

- Vistas:
  - Home
  - Servicios
  - Citas
  - Login
  - Register
  - Nosotros
  - Contacto
  - Blog
  - Reserva
  - Mis citas
  - Panel de administración

## Arquitectura / Tecnología

### Frontend

- Figma para el diseño y prototipado de la interfaz.
- React como librería principal para la construcción de la interfaz de usuario.
- CSS Modules para el estilado modular de componentes.
- Font Awesome Icons para el uso de iconos en la interfaz.
- React Toastify para mostrar notificaciones al usuario.
- Axios para la comunicación con el backend mediante peticiones HTTP.

### Backend

- Laravel como framework principal del backend.
- Eloquent ORM para la gestión de la base de datos mediante modelos.
- MySQL como sistema de gestión de base de datos relacional.

### Despliegue

- Docker para la creación de un entorno contenerizado.
- AWS para el despliegue y alojamiento del backend.
- Vercel para el despliegue del frontend.
